DEQTON iPhone Project

Waxa ku jira:
- www/index.html : DEQTON app-kaaga
- package.json : Capacitor packages
- capacitor.config.json : iPhone app settings

Si iOS project dhab ah loo abuuro:
1. Ku fur project-kan Mac.
2. Terminal-ka project folder-ka ka fur.
3. Orod: npm install
4. Orod: npx cap add ios
5. Orod: npx cap sync ios
6. Orod: npx cap open ios
7. Xcode ka dooro iPhone-kaaga, kadib Run.

App name: DEQTON
Bundle ID: com.deqton.app
